# Dashboard interactif : jeux vidéo

Ce projet R Shiny explore les ventes de jeux vidéo selon le genre, l'année, la plateforme et la région. Les graphiques sont organisés en grille de deux colonnes pour faciliter la comparaison et la lecture. Les filtres permettent de choisir une période, un genre et une plateforme.

## Lancement

Dans RStudio, ouvrez `app.R` et installez si nécessaire les packages `shiny`, `ggplot2`, `dplyr`, `bslib`, `bsicons` et `tidyr`

Les données sont chargées depuis le jeu de données Video Game Sales. Une copie locale nommée `vgsales.csv` peut aussi être placée dans le dossier du projet.
